# Design System & Constraints
- Theme: Dark technical minimalist (background: #09090b, surface: #18181b, border: #27272a).
- Typography: Sans-serif (Geist or Inter) for headings/body; Monospace (JetBrains Mono) for tech badges and dates.
- Spacing: Consistent 8px grid (gap-4, gap-6, p-6). Avoid massive empty paddings.
- Cards: Subtle 1px solid borders, no heavy drop shadows. Hover states with slight border brightening (#3f3f46).
- Layout: Bento-grid style for core metrics/specialties instead of standard vertical 3-column rows.
