# jordirojas-web

Página web personal / CV de Jordi Rojas, arquitecto de sistemas y consultor senior de soluciones cloud especializado en Microsoft Azure.

## Estructura

- `index.html` — Página principal con secciones de hero, sobre mí, experiencia, especialidades, certificaciones, artículos y contacto.
- `styles.css` — Estilos modernos con soporte para tema claro/oscuro.
- `script.js` — Navegación responsive, cambio de tema y animaciones.

## Tecnologías

- HTML5 semántico
- CSS3 con variables y diseño responsive
- JavaScript vanilla
- Google Fonts + Font Awesome

## Desarrollo

Para visualizarla localmente:

```bash
cd ~/.openclaw/workspace/jordirojas-web
python3 -m http.server 8080
```

Luego abre `http://localhost:8080` en el navegador.
